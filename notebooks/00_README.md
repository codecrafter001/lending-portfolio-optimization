# Notebook Guide

## Execution Order

1. **01_data_generation.ipynb** - Generate synthetic lending dataset
2. **02_exploratory_analysis.ipynb** - Explore data distributions and patterns
3. **03_risk_segmentation.ipynb** - Segment customers by risk
4. **04_early_warning_signals.ipynb** - Identify early delinquency indicators
5. **05_strategy_recommendations.ipynb** - Generate policy recommendations

## Outputs

- `data/processed/` - Processed datasets for analysis
- `outputs/visualizations/` - Charts and graphs
- `reports/` - Policy recommendation report

## Key Metrics

- **Default Rate** - % of loans defaulted
- **Days Past Due (DPD)** - Payment delay indicator
- **Customer Lifetime Value (LTV)** - Profitability per customer
- **Risk-Adjusted Return (RAROC)** - Return relative to risk taken
- **Expected Loss (EL)** - PD × LGD × EAD
